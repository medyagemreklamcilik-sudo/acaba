# Pargalı İbrahim neden boğduruldu?

95 sn, 1080x1920. Kanca: "Kanuni, en yakın dostunu iftar sofrasından kalkınca boğdurttu."

## Temkinli verilen noktalar
- "Seni asla öldürmem" yemini ve "uyku ölüm gibidir" fetvası rivayettir; videoda "rivayete göre" diye verildi, ekranda kaynak notu var.
- Duvardaki kan izleri rivayettir.
- Hürrem'in rolü ve İbrahim'in Mustafa'yı desteklemesi "söyleniyordu" diye verildi (kesin kanıt yok).
- İskender Çelebi'nin ölmeden önce İbrahim'i ihanetle suçlaması kroniklerdeki anlatıdır ("anlatılanlara göre").
- İskender Çelebi görseli temsili minyatür.
